一、小火箭与Quantumult概述：了解两款代理工具的优势

1.1 小火箭简介

小火箭作为一款专业的网络代理客户端，以其简洁的界面和丰富的功能广受欢迎。它支持多种代理协议（如Vmess、Shadowsocks、Trojan等），可以灵活配置节点及路由规则，满足不同用户对科学上网的多样化需求。此外，小火箭兼容iOS系统，操作便捷，深受苹果用户青睐。

1.2 Quantumult简介

Quantumult则以更为细腻和深入的配置能力著称。其支持多协议、多规则、多策略的组合，能够精确控制网络请求的路由路径。Quantumult尤其适合对网络环境有较高要求的用户，具备强大的脚本支持和插件扩展能力，适合进行复杂网络环境下的精细化管理。

二、连接转换前的准备工作

2.1 确保软件版本更新

要顺利完成配置转换，首先确保您的设备已安装最新版的小火箭和Quantumult。两款软件均可通过App Store或官方网站获取，保持最新版本能最大程度地保证兼容性和功能稳定。

2.2 获取并备份Quantumult配置文件

Quantumult的配置文件一般后缀为 .quantumult 或 .conf，里面包含节点信息、代理规则及DNS配置。您可以通过论坛、社交平台或者朋友分享获得此配置文件。建议将配置文件备份到设备本地或云端，方便随时导入。

三、小火箭导入Quantumult配置的详细步骤

3.1 在Quantumult中导出配置

  • 打开Quantumult，进入“配置管理”界面。

  • 选择当前正在使用的配置文件，点击“分享”或“导出”。

  • 将配置文件导出为 .quantumult 格式，保存至设备本地。

3.2 在小火箭中导入配置文件

  • 启动小火箭，进入“配置”管理页面。

  • 选择“从文件导入”功能，打开文件管理器定位到Quantumult导出的配置文件。

  • 确认导入，等待小火箭自动解析配置中的节点和规则。

3.3 调整和匹配规则配置

由于两款软件在规则书写和配置格式上存在细微差异，导入后需对规则进行适当调整：

  • 手动检查并修改不兼容的规则格式。

  • 调整DNS设置，确保DNS解析正常。

  • 确认节点分组和策略组配置正确，避免因配置不匹配导致连接失败。

3.4 激活节点并测试网络连接

  • 在小火箭主界面选择目标节点，点击“连接”。

  • 访问常用的外网网站（如Google、YouTube）验证连接是否正常。

  • 若遇到连接问题，尝试切换节点或重新导入配置进行调试。

四、常见问题与解决方案

4.1 如何判断连接是否成功？

连接成功后，小火箭右上角会显示“已连接”状态。同时，可以访问被墙网站检验是否畅通。

4.2 出现“Connection reset”如何处理？

此错误多由服务器响应异常或网络不稳定引起。建议更换节点，检查网络环境，或重启应用。

4.3 Error 403的原因与解决

403错误表示服务器拒绝访问。检查节点是否可用，尝试更换节点或更新配置。

4.4 配置文件导入失败怎么办？

确认配置文件格式正确，并兼容当前小火箭版本。尝试使用在线转换工具或手动编辑配置文件。

4.5 连接不稳定的常见原因及对策

  • 网络环境波动，优选Wi-Fi或有线连接。

  • 节点负载过高，选择负载较低的节点。

  • 配置文件规则过于复杂，简化配置减少干扰。

FAQ

Nekobox 如何管理多协议节点和分流？
Nekobox 可同时管理 Shadowsocks、VMess、Trojan 等多协议节点。结合策略组和分流规则，可实现不同流量走不同节点，提升网络效率和管理便利性。
SSR 是否支持 UDP 协议转发？
原版 SSR 并不完全支持 UDP 转发，但部分魔改版本（如 SSRR）支持该功能。可在配置中开启 udp-over-tcp 模式或使用 Socks5 UDP relay 方案实现游戏等实时通信的代理需求。
Nekobox 是否支持多客户端同时管理节点？
支持。Nekobox 可以独立管理多个客户端，如 Shadowsocks 和 Clash 节点，互不干扰。结合策略组，可实现多客户端流量分流和网络优化，提高便利性和效率。
Matsuri 日志太多如何调整日志级别？
在 Matsuri 或其内核配置中修改日志级别参数（如从 debug 降为 info 或 warning），同时限制日志轮转与最大文件大小。生产环境建议关闭 debug 日志以减少磁盘 I/O 与性能影响。
Hysteria2 协议的主要特点是什么？
Hysteria2 是新一代基于 QUIC 的高速代理协议，支持自适应拥塞控制和零 RTT 连接。相比传统 TCP 协议，它能在高延迟或丢包环境下保持稳定速度，特别适合跨境访问或实时传输场景。
V2Ray 的路由规则如何实现按应用分流？
V2Ray 支持按用户标签或端口匹配应用流量，结合策略组可实现指定应用走特定节点。这样可以保证游戏、视频和浏览器流量各自走最优线路，提高访问效率。
SSR 节点和 V2Ray 节点可以混合使用吗？
可以，但要使用支持多协议的客户端，如 Clash、Sing-box、Mihomo 等。这类客户端能在同一配置文件中加载不同协议的节点，通过规则分流让 SSR 与 V2Ray 同时工作。
SSR 的 obfs 混淆原理是什么？
SSR 的 obfs 模块通过模拟常见流量特征（如 HTTPS 或 HTTP 请求头）来掩盖加密流量。这样可让代理流量看起来像正常的网页访问，从而有效降低被检测和封锁的风险。
VMess AEAD 加密在高封锁地区的优势？
AEAD 加密可防止数据篡改和流量特征泄露，降低被 DPI 检测风险。在高封锁地区使用，可保证节点长期稳定可用，同时提升数据传输安全性和访问可靠性。
Nekobox 是否可以管理多客户端节点？
可以。Nekobox 与 Shadowsocks、Clash 等客户端独立运行，互不干扰。结合策略组使用，可灵活分配节点，实现多客户端管理和流量优化。
